# 👨🏻‍💻 Nicolas de Paula

**`Desenvolvimento de Software | Automação de Processos | Dados`**

Me chamo Nicolas de Paula, sou estudante de Análise e Desenvolvimento de Sistemas na Universidade Cruzeiro do Sul e técnico em Informática e Cibersegurança pelo SENAC.

Atualmente, atuo na área de Suporte Comercial, onde tenho experiência prática com automação de processos, estruturação e análise de dados, controle de estoque, SAP, Excel avançado e Power BI.

Na área de desenvolvimento, venho trabalhando principalmente com Java, Python e JavaScript, desenvolvendo aplicações, APIs e projetos envolvendo bancos de dados e integração de sistemas.

Tenho interesse em desenvolvimento de software, backend, automação, dados e engenharia de software, buscando constantemente transformar problemas reais em soluções utilizando tecnologia.
